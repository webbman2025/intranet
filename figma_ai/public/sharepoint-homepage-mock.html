Revamp UX principles

Legacy frameset → single SharePoint communication site (hub)

Remove

  • Two-frame layout (menu_top + menu_right)
  • Hand-edited HTML announcements
  • Mixed hosts opening in random targets (_blank / main)
  • Table-based layout and fixed 184px header

SharePoint build

  • Hub site — top nav = associated department site links (Finance on separate site collection if needed)
  • News — “What’s Hot” from News posts; metadata: Department, Expiry, Featured
  • Hero — top story + CTA to PDF/page in document library
  • Quick Links — Online apps + Popular items (two web parts or grouped links)
  • Search — Microsoft Search verticals: People, Policies, Forms, News
  • Viva Connections (optional) — same links in Teams mobile dashboard

IA mapping

  • Dept bar → Hub navigation + Department cards
  • Jetso / newsletter PDFs → HR or Comms site document libraries
  • popitems/ → Global navigation “Resources” hub page
  • External SaaS (Oracle, CKHH) → Quick links with “opens externally” icon

Accessibility & mobile

  • One H1, logical heading order, keyboard nav
  • Responsive sections stack; hub nav becomes horizontal scroll or menu flyout
  • Support English + Traditional Chinese (legacy Big5 content migration)

Brand

  • Primary #012D90, accent #FF6600 (SharePoint theme + section backgrounds)
  • Segoe UI / Fluent icons in production (mock uses text icons)
